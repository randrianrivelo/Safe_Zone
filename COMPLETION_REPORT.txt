Pour démarrer le projet maintenant:

1. PREMIÈRE FOIS - Configuration initiale:
   
   # Option 1: Interactive
   python setup.py
   
   # Option 2: Manuel
   cd smart-safezone/backend/database
   ./setup.sh  (ou setup.bat sur Windows)

2. DÉMARRER LE BACKEND:
   
   cd smart-safezone/backend
   ./run.sh  (ou run.bat sur Windows)
   
   ➜ http://localhost:8000
   ➜ Documentation: http://localhost:8000/docs

3. TESTER L'API:
   
   python test_api.py
   
   Teste 6 endpoints principaux

4. DÉMARRER LE FRONTEND (optionnel):
   
   cd smart-safezone/frontend
   npm install
   npm run dev
   
   ➜ http://localhost:5173
